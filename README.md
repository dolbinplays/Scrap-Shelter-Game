# Scrap Shelter v0.26.06.03.1808 - Puzzle Visibility UX Fix

This patch fixes the Stage 1 puzzle usability issue where it was unclear how to place parts and placed parts could be easy to miss.

## Changes
- Auto-selects the first available part piece when a salvage puzzle starts.
- Adds clear on-screen instructions above the puzzle board.
- Adds a selected-part banner telling the player what to do next.
- Highlights valid board anchor cells in green and invalid anchors in red.
- Adds stronger visual styling and entry animation for placed tiles.
- Updates puzzle log text to explain the action loop.

## How to play the puzzle
1. Go to Puzzle.
2. A part is selected automatically. You can tap a different part below the board if desired.
3. Tap a green square on the board to place that part using the tapped square as the top-left anchor.
4. Fill rows or columns to clear them into Scrap, Gears, Wiring, or Batteries.
5. Tap Claim Salvage & Return to add the recovered parts to the base inventory.
